# Test cuts batch 4: per-item reasoning (2026-11-06)

Plan: `reports/2026-11-06-test-cuts.md` on `origin/chris/test-cuts`, section 2 "Batch 4" (69 items, 921 one-worker s).
Scope rules from the task: old-runner / legacy-runner compat rows excluded, cloud_machines trims excluded,
`test_schema_every_table.py::test_every_table_of_an_upgraded_database_has_the_columns_of_a_new_one` kept.

Rules applied to every item: `git log origin/main -S'<name>'` checked for the names touched (the search was run on
`origin/main` only, since the plan branch itself mentions every name). A case from a fix, guard or regression commit
is kept. A fold keeps every assertion, with an assert message that names the case. A test whose module- or
session-scoped fixture is already shared between its siblings is not folded, because the fold saves no one-worker
seconds.
