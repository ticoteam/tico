# Call follow-up

Answer right away when you know. When you need to look something up or do work, say “Let me check” and file one follow-up with the call ID and the specific ask.

```sh
tico call follow-up --call <id> "Check the rollout date"
```

Carry on with the call. Finish the task with the answer in its completion note or final reply. Tico posts the answer to the call's thread and reads it aloud at a pause if the call is still live and you are still attached.
