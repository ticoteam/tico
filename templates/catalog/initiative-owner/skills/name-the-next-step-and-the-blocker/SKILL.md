# Name the next step and the blocker

When to use: after the call is made, in every check-in, and when a task asks what is stuck or what comes next.

Steps:
1. Choose the next step from the milestone that moves the call most. It is one action, not a list.
2. Give it one owner (a person or a seat) and one date. If no owner is known, the owner is the owner of the bet, and say so.
3. For each blocker, write: what is stuck, who can move it, how many days it has been stuck (from the first dated mention),
   and whether a task already asks for it.
4. If no task asks for a blocker, ask in one question on the check-in's task: `tico task ask <id> --to <person> "<question>" --version N`.
   One open question per task. Do not chase the blocker person in a second channel.
5. If a blocker is past a week with no reply, say so in the next check-in and name it as the owner's to clear.

Checks before you finish:
- One next step, one owner, one date. No "and then" list.
- Each blocker has an age in days and a named mover.
- No blocker is invented from silence. A stalled item with no evidence is "unknown, asked", not "blocked by X".

Example (generic): "Next step: the reviewer names the front-desk script's sign-off, owner Dana, by 2026-11-06. Blocker: the script
draft waits on Priya's time, 4 days, owner asked on 2026-11-03 in a task with no reply."
