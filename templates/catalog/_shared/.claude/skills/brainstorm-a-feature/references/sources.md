# Sources

All text in this skill is original. The ideas below were adapted; no wording was copied. Read 2026-11-18.

## Adapted (MIT or Apache-2.0)

- **Anthropic, `knowledge-work-plugins`, product-management, `product-brainstorming`** (Apache-2.0). https://github.com/anthropics/knowledge-work-plugins/blob/main/product-management/skills/product-brainstorming/SKILL.md
  Taken: the rhythm of frame, diverge, provoke, converge, capture; asking for the strongest argument against an idea; ending with two or three ideas, each with its biggest unknown and the cheapest way to resolve it; including an option that removes something; the list of common traps.
- **obra/superpowers, `brainstorming`** (MIT). https://github.com/obra/superpowers/blob/main/skills/brainstorming/SKILL.md
  Taken: read what the project already answers before asking anything; lay out a few approaches and recommend one; nothing is built from the conversation alone.
- **garrytan/gstack, `office-hours`** (MIT). https://github.com/garrytan/gstack/blob/main/office-hours/SKILL.md
  Taken: challenge the premise before proposing any solution, and write premises as statements that can be agreed with or rejected. Its startup diagnostic questions live in a separate file that was not read and are not used here.
- **mattpocock/skills, `grilling`** (MIT). https://github.com/mattpocock/skills/blob/main/skills/productivity/grilling/SKILL.md
  Taken: finding facts is the bot's job, never the person's; word a question so "yes" accepts the recommended answer.

## Defaults that are this skill's own

"At least seven options", "at most three candidates", "three accounts from two kinds of source is a pattern" and "a test that fits in a week" are working defaults, not published standards. The pattern threshold matches the Feature Owner template's ranking rule. A team may change them in `knowledge/product.md`.
