One stall system

This is a spec to make stuck tasks, blocked ones too, wake their agent instead of a person. About 4 build days.

Today and after

Today

Build stage rules
Owner on the team   block
Quiet agent tasks   6 h, not blocked
Late                hidden, built in

After

Build stage rules
Owner on the team   block
Quiet agent tasks   6 h, blocked too
Late                24 h, owner agent
  • Late becomes a rule each stage shows and can edit; the manager hears 6 h after the agent.
  • No timer ever hands a task to a person.

Why now

  • All 4 blocked tasks on Tico Team sat 35 to 72 h with nobody told.
  • Late fired 202 times on 175 tasks in 14 days; 22 fired twice; none was on a person's own task.

Done when

  1. Given any stage, when its rules open, then a Late rule shows with its hours. before release
  2. Given a task behind a quiet blocker for 6 h, then its owner agent wakes once. before release
  3. Given any timer firing, then no message goes to a person. before release

Scope

  • In: Late as a rule, blocked tasks in Quiet agent tasks, one wake per stall.
  • Out: timers on a person's own tasks; they decide when to look.

Plan

  1. Move the built-in Late timer into the stage rules; about 400 lines out, 120 in.
  2. Count blocked tasks in Quiet agent tasks, once per stall.
