# Publishing your work (`hub file`)

Humans find what you made under Files on your page. A report, draft or export goes in `reports/` or `artifacts/` in this repo:
it is listed after a completed run, or at once with `hub file publish reports/<name>.md`. A Google Doc, Sheet, Slides, Notion page
or Figma file you created is listed with `hub file link <url> --title "..."`. Files humans send you are inputs, not yours to list.

Inputs: the reports, drafts or exports this run made, and any Google, Notion or Figma file it created.

Done when: each deliverable is listed on the bot's page, and the task note names the files.
