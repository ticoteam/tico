One file per recurring kind of work. A playbook is the checklist you would hand a new hire. Read the one that matches the
request before you act; AGENT.md says when for the rest.

Inputs: the request or task in hand. Find the playbook that matches it below.

Done when: the matching playbook has been read and its own Done when line is met.

## Chat requests from a human (as them)
- `build-me-a-bot.md`: build a bot and take it live.
- `change-model-or-computer.md`: a model change or a move, checked on the computer.
- `health-check.md`: what is broken, and the fixes you may make right away.
- `connect-a-tool.md`: connect a tool (the vendor's MCP server first, else a skill in the bot's repo; credentials).
- `share-a-credential.md`: give another bot a credential one bot has.
- `turn-on-sending.md`: let a message bot's mail go out, to the recipients the human names.
- `connect-a-hermes-profile.md`: connect a Hermes or OpenClaw profile with a pairing code, ask how often it syncs, and fix one
  that is not reporting in or was archived.
- `copy-a-bot.md`: copy a bot, bring a copy up to date with its original, suggest its changes back. A copy is an ordinary bot
  the requester owns; nothing stays linked until they ask.
- `copy-a-skill.md`: copy a skill from one bot to others.
- `set-up-a-bot.md`: a new bot's repository, from the template.
- `set-up-a-watcher.md`: a watcher script in a bot's software folder.
- `diagnose-a-failed-run.md`: why a run failed, and what to fix.

## Settings and access
- `commands.md`: the commands that do what a settings page would.
- `credentials.md`: Credentials, before any credential is handled.
- `rights.md`: whose rights a command uses, and follow-through for a person's request.
- `refusals.md`: permission refusals, `retryable: false`, Tico bugs, computer updates.
- `archive-and-cleanup.md`: archive, restore, deletion and cleanup.

## Tasks and files
- `human-tasks.md`: tasks you file for a person, and the cards that ask for a choice.
- `task-sweep.md`: the daily sweep of open tasks.
- `publish-a-file.md`: reports, drafts and exports a human should find.
