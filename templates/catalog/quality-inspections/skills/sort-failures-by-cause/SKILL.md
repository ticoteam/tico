# Sort failures by cause

When to use: when you write a re-do's cause, when an item fails in more than one job, or before you propose a checklist change or raise a crew with the Operations Manager.

Steps:
1. Read the failed item and its pass standard in `knowledge/checklists.md`. If the standard is missing, vague ("clean", "good finish") or does not say what the photo must show, the cause is at least partly a system cause. Stop here and record it.
2. Read the photo or the inspector's note. If the photo does not show the pass standard, the item cannot be judged on that evidence; say so.
3. Look at the same item across the last 8 weeks in `knowledge/inspection-log.md` and `knowledge/redos.md`. Count the failures by crew and by job type.
4. Apply the test:
   - Two or more crews fail the same item, or one inspector sees it fail across crews: system cause (standard, training, equipment or supplies).
   - One crew fails it repeatedly, and the other crews pass it on similar jobs: crew cause, to be checked with the Operations Manager.
   - One failure in one job: not yet a pattern. Record it and wait for a second.
5. Write one cause from the list in `knowledge/quality-method.md`. If two causes apply, record the main one and name the other.
6. For a system cause, write the change as a proposal: the item, the new pass standard in one line, and the photo that proves it. It goes to the person who approves checklist changes. The checklist itself does not change in this run.
7. For a crew cause, write the facts only: the item, the jobs, the dates, and what the other crews did on the same jobs. No conclusion about the person.

Checks before you finish:
- Each failure has one cause, and a system cause has its proposal.
- No crew is named as the cause of an item that more than one crew fails.
- The evidence is named: the photo, the job, the date, the count.
- Nothing in the note is a judgement of a person.

Example (generic): "Oven interiors failed in crews A, B and C over 8 weeks (3 jobs, 3 crews). The standard says 'oven clean'. System cause: unclear standard. Proposal: 'no residue on racks or door glass; photo of the door glass'. Window frames failed once, crew C, 2026-10-02: one failure, recorded, not yet a pattern."
