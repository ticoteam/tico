# Set a pay range for a job post

When to use: when a job post is due and the role has a band, or when a task asks for the range a posting should state.

Steps:
1. Find the band for the role family and level in `knowledge/bands.md`. If there is none, the post waits for a band. A
   provisional band goes to the owner for a yes before it is posted.
2. Use the band's minimum and maximum as the range for the level. Do not narrow the range to fit a candidate, and do not
   quote an offer.
3. Check the rules for every place the job can be done from, not only the employer's location. Many laws cover a remote role
   that a person can do from their state, so list the states the post reaches.
4. Write the range with its unit (for example "base salary a year"), its currency, and a note on any bonus or equity that sits
   outside it.
5. Compare with the last posting for the same level. If the range differs, record why in the note.
6. Attach the text to the task for the recruiter. A person publishes the post.

Checks before you finish:
- The range equals the band for the level, or the difference is stated and approved.
- The unit and currency are written.
- Every place the job can be done from was checked against its rule.
- The range is not a candidate's offer.
- The band's date is named, and a provisional band has the owner's yes.

Example (invented, for illustration): "Product designer, level 2. Band 90,000 to 115,000 a year, set 2026-07-14. Posting text:
'Base salary $90,000 to $115,000 a year. Bonus and equity are not included in this range.' The role can be done from two
states that require a posted range, so both are checked and the range is included."
