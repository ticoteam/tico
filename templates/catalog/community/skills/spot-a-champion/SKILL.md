# Spot a champion

When to use: in each weekly digest, and when a member's answer stands out in a thread.

Steps:
1. Find the members who answered questions in the period, using only their public posts in the connected sources.
2. Check each answer against the docs with `hub doc ask`, or with the Librarian. Count an answer as correct only if it matches the docs or a team member confirmed it. Active is not the same as right.
3. Count the correct answers across the period and note each thread link. One answer is a note. Correct answers across several weeks make a champion.
4. Record the champion in `knowledge/champions.md`: public name, what they did, the dates and links, and the last date thanked (blank if never). Nothing else about them.
5. Thank a champion by name in public only after a person approves the reply. Record the date the thanks was approved.
6. Review the list once a month. Remove anyone who asked to be left off, or whose answers were wrong in the period.

Checks before you finish:
- Each entry has a public name, a link and a date.
- Each answer counted was checked against a source.
- No contact details, account data or private messages appear in the file.
- A person approved any thanks before it was posted.

Example (generic): "A member answered four how-to threads in the week of 2026-09-14. Three matched the docs; one was partly right and the reply corrected it. Recorded in the champions list: public name, four links, 2026-09-18, last thanked blank. A thank-you is drafted for approval, naming the checked answers."
