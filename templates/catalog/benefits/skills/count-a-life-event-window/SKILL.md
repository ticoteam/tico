# Count a life-event window

When to use: before you state a close date, days left or a "submit by" date for any change window, on the weekly page, a
change-log line or a task note.

Steps:
1. Take the event date from the record: the date the event happened, not the date it was reported. If the record gives only
   a month, write "date unknown" and ask on the task. Do not guess the day.
2. Find the window rule in the plan document. Ask the Librarian (`hub doc ask "<plan> change window after <event>"`), then
   read the page it cites whole. Record the length, the unit (calendar or working days), and whether it runs from the event
   or from the notice.
3. Count. Add the days to the start point the plan names: the event date, or the notice date where the plan counts from the notice. If the close lands on a weekend or holiday, follow the rule the plan states. If the
   plan is silent, write "closes on <date>, weekend rule not stated" and ask. Do not assume an extension.
4. Days left = close date minus the date of this page. Zero is "due today": the cutoff day is still open. Less than zero is "closed", and only once the applicable cutoff has passed.
5. Compare with what was submitted. A closed window with no submission is reported plainly, with its date.
6. Write the line: reference, event, event date, close date, the rule and its page, days left. Seven or fewer days left is
   bold and goes to the top.

Checks before you finish:
- The event date comes from the record, and the source is named.
- The rule has its plan, page and plan year.
- The unit (calendar or working days) and the start point (event or notice) are stated.
- Days left is counted from this page's date, and that date is written.
- A rule you could not find is "unknown", not a default number.

Example (invented, for illustration): "LE-2026-03, marriage, event 2026-09-14. Plan guide 2026, p. 7: 30 calendar days from
the event to request a change. Close 2026-10-14. Page dated 2026-10-01: 13 days left. Provider needs the marriage
certificate. Not submitted."
