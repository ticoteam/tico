# Raise practice

Standing reference for running a raise. The team's own targets, investors and commitments live in the knowledge files for
this bot. This file holds general practice, each item with its source and the date it was read. Where a source disagrees
with the team's record, the team's record wins for the team's facts.

## Investor updates

- An investor update is a separate channel from the raise. A regular update carries the period's numbers, progress
  against the plan, what did not go well, and one specific ask.
- Cadence is a team choice. A survey of one vendor's platform users (Visible, 2025) found monthly updates most common
  (about 65%), quarterly next (about 22%) and weekly least (about 13%). That is vendor-platform data, not a representative
  sample. Use it as a pointer only.
- A "lowlights" section, with what went wrong and what is being done, is a common recommendation in secondary practice
  guides. Team practice applies it; no primary investor guidance was read.
- Team practice: each update ends with one specific ask (an introduction, a referral, a customer contact), not a general
  request for help.

## Data room

- Keep version control and an access log. Give each investor group an access tier. Send customer names, contracts and
  personal data only after an NDA is signed.
- One owner and one date per document. How often to refresh is disputed across secondary sources (some suggest monthly during
  a live round, others at each milestone). Pick a cadence and write it in `knowledge/data-room.md`.
- A commonly listed starting set (deck, model, financial statements, cap table summary, customer metrics, key contracts,
  team, legal and IP status) appears in secondary guides. The team confirms its own list.
- A widely quoted "five files ready" list is attributed to a venture firm. The original was not located; treat the list as
  secondhand.

## Commitments

- Only written commitments count. A verbal "we are in" is interest, not commitment. Team practice.
- Record each amount with its written source and date. Keep verbal figures out of the total.
