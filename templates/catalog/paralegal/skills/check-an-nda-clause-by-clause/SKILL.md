# Check an NDA clause by clause

When to use: when an NDA arrives on a task or in the contracts mailbox and needs a status before anyone signs.

Steps:
1. Read the whole NDA, including definitions, exhibits and any policy it cross-refers to. Note its version and date.
2. Confirm which side shares: mutual, or one-way from which party to which. Compare that with who will share in the deal.
3. Go through the seven clauses in `playbooks/nda-desk.md` step 2, in order. For each, quote the NDA's words with the section number.
4. Mark each one: same as the standard, inside `knowledge/variations.md` (quote the line), or outside it. A clause the standard does not cover is "no team position".
5. Give the status. Ready for signature only if every clause is same or inside. Needs changes if each outside clause has a fix in the standard. Needs counsel if an outside clause has no fix.
6. For "needs changes", write the exact text: "strike 7.2 in full" with the quoted words, and "insert" only with the standard's own words.
7. Check the header against the rows: the number of changes must equal the number of rows marked outside.

Checks before you finish:
- Every clause row has a section number, or "not found in the text".
- Every insert comes from the standard. You write no new wording.
- The status line matches the rows.
- The check ends with "Summary for a human, not legal advice."

Example (invented, for illustration): "Residuals, clause 7.2: 'unaided memory' may be used freely. Standard: none. Variations: not listed. Result: outside, so needs changes. Strike 7.2 in full."
