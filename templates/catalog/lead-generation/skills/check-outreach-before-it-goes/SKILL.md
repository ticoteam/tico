# Check a list before hand-off

When to use: before any target list is handed to `sdr-research` for first touch. This check never sends anything. It ends with a hand-off note, and the SDR decides first touch.

Steps:
1. Name the list, its size and the Sales Development Representative who will take first touch.
2. Write the consent basis for each source: a business contact from a public source with a stated purpose, an opt-in, or an existing relationship. Name the country where it matters, and the rule to a person rather than from memory.
3. Check each row against the do-not-contact list in `knowledge/do-not-contact.md` and any request to stop. Remove a match and record the removal with its date.
4. Check accuracy: each row's fit fact matches its dated source, and each row has a source and a check date. Send back any row without one.
5. Note the first-touch rules for the SDR: a working opt-out and a valid physical postal address in each commercial email, under the CAN-SPAM Act (15 U.S.C. 7701 and following). The SDR checks the message itself.
6. Write the hand-off on the task: the list, its sources and dates, the checks and their results, the rows still to verify, and that nothing was sent.

Checks before you finish:
- Each source has a consent basis, or its rows are removed.
- Every do-not-contact and stop request was checked, with the date.
- Each row has a fit reason with its dated source, and every row is marked to verify.
- The hand-off says nothing was sent and names sdr-research for first touch.

Example (invented, for illustration): "Hand-off to sdr-research: regional fleets list, 11 rows, all marked to verify. Source: association member directory, read 2026-11-02. Consent basis: business contact on a public page, purpose stated on the source. Removed 2 rows that asked to stop last year. Accuracy checked against each row's dated source. First-touch rules noted for the SDR. Nothing sent."
