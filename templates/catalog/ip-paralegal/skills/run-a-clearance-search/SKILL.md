# Run a clearance search

When to use: when a task proposes a product, feature or team name.

Steps:
1. Pin down the name, any logo, the goods or services, the countries and the launch date. Ask once for anything missing, because the search depends on it.
2. Search each named country's trademark database: the exact word, then spelling, sound, plural, split or joined forms and translations where they are obvious, in the likely classes and the related ones.
3. Check the team's own register, so the team's marks are not flagged as conflicts.
4. Search the web and the main app and marketplace listings for the name with the product words.
5. Check domain availability for the obvious domains, read only.
6. Record each database, term, class and the date searched.
7. Sort the results: identical or near-identical marks on related goods first; similar marks next; the same word on unrelated goods counted; unregistered uses listed with the link and the date seen.
8. Write the note for `reports/clearance/<name>.md`, and put it on the task for counsel.

Checks before you finish:
- Every database, term, class and date is listed.
- Nothing says the name is free to use or registrable.
- "Nothing found" states what was searched.
- Counsel is asked the questions the search could not answer.

Example (invented, for illustration): "Searched: USPTO, term 'AKME FLO', classes 9 and 42, 2026-10-01. Found: one application in class 9, filed 2026-09-08, sounds the same, goods related. Listed first."
