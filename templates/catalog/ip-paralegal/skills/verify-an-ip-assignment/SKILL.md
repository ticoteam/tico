# Verify an IP assignment

When to use: each month, and whenever someone new has created work for the team as a founder, employee or contractor.

Steps:
1. List each person who created code, designs, names, logos or content for the team, with what they made and when.
2. Find the agreement in the docs or on a task. If none is found, mark the person "not seen".
3. Read the assignment clause and quote its words. Note whether it covers work made before the agreement as well as after.
4. Mark each person "assigns", "does not", or "not seen". A licence is "does not".
5. For "does not" or "not seen", list the person in `knowledge/assignments.md` and tell the decision-maker. Do not contact the person.
6. Raise any question about whether work was made for hire as a question for counsel, and do not answer it.

Checks before you finish:
- Each person has exactly one mark.
- Each "assigns" mark quotes the clause and its date.
- Work made before the agreement is flagged, not assumed to be covered.
- No one was contacted.

Example (invented, for illustration): "Lena, contract designer, logo and app screens (2021). Agreement dated 2021-02-02, clause 6: 'the Designer grants the Company a licence'. No assignment words. Mark: does not."
