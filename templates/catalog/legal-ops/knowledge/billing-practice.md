# Billing practice

Standing practice for reading outside counsel invoices. It is practice for the desk, not legal advice, and it does
not judge the quality of any legal work. The team's own letters and billing rules override anything here.

## Invoice format
- LEDES 1998B is a common US electronic invoice format. Each time line carries a task code and an activity code
  from the UTBMS set. An activity code is used with its task code. Expense lines usually leave the task field empty.
  Source: Thomson Reuters Legal Tracker file specifications, seen in search 2026-11-01. The field spec itself is on
  LEDES.org and was not opened in this run.
- UTBMS task codes name the type of work and activity codes name the action, for example L110 for fact investigation
  and development and L310 for written discovery; trial preparation uses L4xx codes. Source: UTBMS description, seen in
  search 2026-11-01. Confirm which code set each firm uses.
- Blank task or activity fields, and codes from the wrong set, are the usual validation failures. Ask the firm to
  resend the file rather than editing it yourself.

## Units and blocks
- Engagement letters often bill in increments such as 0.1 hour. The team default is 0.1 hour, marked as a default
  until the owner confirms it against each letter.
- Block billing puts several tasks in one entry with one total. It hides which task took the time. Ask for the
  entry to be split by task.

## Rates and the letter
- ABA Model Rule 1.5(b): the scope of the representation and the basis or rate of the fee and expenses are to be
  communicated to the client, preferably in writing. State versions differ, and some require writing. Source: search
  summaries of the rule text, 2026-11-01. The ABA page returned HTTP 403 when fetched in this run, so the text was not
  re-read at source. Check the version in the state where the firm is licensed.
- A rate above the letter is a question with a cited line, not a finding.

## Records
- Two invoices from one firm can disagree. Record both with their dates; do not average them.
- A missing letter is said at the top of the review, not guessed around.
