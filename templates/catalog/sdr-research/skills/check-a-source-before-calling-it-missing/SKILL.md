# Check a source before calling it missing

When to use: before a research note says a company, person, page, address or fact does not exist, is not listed, or has no evidence.

Steps:
1. Name the sources you checked, with the date you checked each one.
2. Check the archived versions of the source, not only the current page. A page that hides a detail today may have shown it in an earlier layout.
3. Count live pages, not sitemap entries. Sitemaps keep pages that were removed.
4. Search every legal name and every spelling you have. One name can belong to a company, a person or a building. Check each match before you count it.
5. Keep the search limits in the note: which fields were searched, which were not readable, and which needed a login you did not have.
6. Report the result as "not found in <sources>, checked <date>". Do not report "does not exist".
7. When you need a list of candidates, freeze the list before any write. Paginate over a fixed snapshot, not over a filter that shrinks as you change records.

Checks before you finish:
- Each "not found" names its sources and dates.
- An archive was checked where one exists.
- Every match was checked against the entity you are reporting on.
- Limits are written in the note, next to the result.

Example (invented, for illustration): "Firm X: no contact page on its current site (read 2026-10-20). Archived 2012 to 2016 pages print a street address and phone; the address matches a registered office in a public register (read 2026-10-21). Result: address found in an archived source; current status unknown."
