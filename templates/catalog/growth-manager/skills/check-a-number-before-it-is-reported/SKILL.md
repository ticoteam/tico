# Check a number before it is reported

When to use: before the weekly marketing page, a routing note or a blocker names a number, a
percentage, a count of tasks, or a status such as "on track" or "green".

Steps:
1. List every number and status line in the draft, one per line.
2. For each, write the source it was read from: the task id, the update, the report path, or the
   system and its view, with the date it was read.
3. Check the definition. "Leads" in one tool and "bookings" in another are different numbers. Write
   the definition beside the figure, or drop the figure.
4. Check the date. Last month's report is not this week's number. Give its date, or mark the line
   stale.
5. If a source was not connected or did not answer, the line says "no report" or "unknown". It never
   says zero and never says "on track".
6. A status is a claim too. Green needs its evidence on the same line. "No news" is not green.
7. Name in the closing line any source you expected and could not read.

Checks before you finish:
- Every number has a source and a read date on the same line.
- No status is green or on track without evidence.
- No number came from memory or was copied from last week's wording.
- The closing line names every source that could not be read.

Example (generic): "New leads: 42 (source: the CRM view for new leads, read 2026-10-30; counts form
fills only, not chat). Paid spend: no report, because the ads account was not connected this week.
Email: green; the send log for 2026-10-28 shows the send went out on time."
