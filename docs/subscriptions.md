# Subscriptions

Subscriptions are now part of [Computers](computers.md). A subscription is the computer's login for an AI tool: one
per tool per computer, used by all its bots. Sign it in and read its usage in the computer's pop-up on
**Settings → Computers**. For a different account, add another computer, which can be on the same machine.
